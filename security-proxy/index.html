⚠️ Frontend Build Required

The React frontend needs to be rebuilt with Node.js 20+ to see the latest changes.

📋 Build Instructions

To build and deploy the updated frontend with the new navigation and dashboard:

  1. Upgrade Node.js to version 20.19+ or 22.12+:
    nvm install 20 or nvm install 22
  2. Build the frontend:
    cd /home/asna/synorix && npm run build
  3. Copy build files to security-proxy:
    cp -r dist/* security-proxy/
  4. Restart the security-proxy service
